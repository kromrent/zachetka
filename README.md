# Зачётка

Персональное PWA для подготовки к вступительному экзамену по программам 09.04.01.

## Возможности

- тесты по 8 вопросов с одним правильным ответом;
- мини-тест из 8 заданий к каждому теоретическому вопросу, с объяснениями и повтором;
- письменные ответы с AI-оценкой по официальной шкале 0–25;
- общие редактируемые заметки к теоретическим вопросам в письменном режиме, полном билете и лекциях;
- Java-задачи из экзаменационной программы с редактором и AI-оценкой 0–50;
- полный билет: два вопроса и задача, 60 минут, максимум 100 баллов;
- аудиолекции по отдельным вопросам и разделам с раскрываемым текстом озвучки;
- локальное сохранение прогресса и черновика;
- установка на главный экран телефона как PWA и офлайн-загрузка интерфейса.

В папке `extracted/ocr` находится локально распознанный текст всех трёх исходных PDF.

## Запуск

```bash
npm install
cp .env.example .env
npm run dev
```

Интерфейс откроется на адресе Vite, API работает на `http://localhost:8787`.

Для production:

```bash
npm run build
npm start
```

После сборки единый сервер отдаёт приложение и API на `http://localhost:8787`.

## AI-проверка

В `.env` необходимо указать `OPENAI_API_KEY`. Ключ используется только сервером и не попадает в браузер. По умолчанию применяется `gpt-5.6-luna`; модель можно заменить через `OPENAI_MODEL`.

Без ключа тесты, редактор, таймер и локальный прогресс работают, а AI-проверка показывает понятное сообщение о настройке.

Мини-тесты по отдельным вопросам создаются только после нажатия пользователя. Для них можно указать отдельную модель с поддержкой Structured Outputs через `OPENAI_QUIZ_MODEL`; иначе используется `OPENAI_MODEL`.

Точный текст каждой новой лекции сохраняется в общей PostgreSQL-базе до озвучки и затем используется для MP3 без изменений. Для старых MP3 текст восстанавливается только при первом открытии панели через `OPENAI_TRANSCRIBE_MODEL` (по умолчанию `gpt-4o-mini-transcribe`), поэтому такая запись помечается как автоматическая расшифровка. Повторные открытия читают сохранённый текст и не вызывают OpenAI.

## Заметки к вопросам

К каждому теоретическому вопросу можно добавить заметку до 4000 символов. Одна и та же заметка открывается и редактируется в режиме «Письменный ответ», в полном билете и в лекциях. Редактор находится в `src/QuestionNotes.tsx`.

Заметки автоматически сохраняются локально в `exam-question-notes`, а после входа попадают в обычную синхронизацию прогресса. Вопрос определяется стабильным ключом `${subjectId}:${sectionIndex}-${questionIndex}`, а не его текстом.

Локальный маркер `zachetka-question-notes-owner` отделяет заметки разных аккаунтов на одном устройстве. При смене пользователя приложение очищает чужую локальную копию и заново загружает заметки вошедшего аккаунта.

При первой гидратации локальные и серверные заметки объединяются по ключу вопроса и `updatedAt`. Серверный `PUT /api/progress` делает тот же per-key merge в транзакции с `SELECT ... FOR UPDATE`. Пустая запись с более новым `updatedAt` служит tombstone, чтобы удалённая заметка не восстанавливалась с другого устройства.

## Мини-тесты к вопросам

В карточках, письменном режиме, библиотеке ответов и лекциях можно открыть мини-тест по текущему теоретическому вопросу. В полном билете он появляется только после завершения экзамена. Каждый набор содержит 8 вопросов по 4 варианта, после ответа показывает короткое объяснение, а при повторе перемешивает задания и варианты.

Первое нажатие для ещё не подготовленной темы вызывает OpenAI. Набор сохраняется в PostgreSQL `question_quiz` и становится общим для всех пользователей, поэтому повторные прохождения и открытия уже готового теста не требуют новой генерации. Массовой фоновой генерации нет: это защищает баланс от 198 одновременных запросов.

Личный результат хранится в `exam-question-quiz-progress`, синхронизируется с аккаунтом и отображается в прогрессе. Тема считается освоенной при результате не ниже 6 из 8; лучший балл не уменьшается после более слабой попытки.

## Java

`ENABLE_LOCAL_JAVA=true` включает локальную проверку компиляции через `javac`. Использовать её следует только на личном компьютере. Она не является безопасной песочницей для публичного сервера. На хостинге выполнение кода нужно вынести в отдельный изолированный контейнер с лимитами CPU, памяти, времени и без сети.

## Телефон

После размещения приложения на HTTPS открой ссылку в браузере телефона и выбери «Добавить на главный экран». Интерфейс и сохранённый прогресс доступны как PWA; AI-проверке требуется интернет.

## Аккаунт и база

Приложение использует PostgreSQL. Подключение задаётся переменной
`DATABASE_URL`; локально можно использовать базу `zachetka` из Postgres.app,
а на хостинге — выданную облачным PostgreSQL строку. Пароли хешируются через `scrypt`, а сессия
хранится в защищённой `HttpOnly` cookie.

После регистрации локальный прогресс загружается в аккаунт. Изученные вопросы,
черновики, заметки, результаты, задачи и эталонные ответы затем синхронизируются
автоматически. AI-маршруты доступны только авторизованному пользователю, поэтому
публичная ссылка не позволяет посторонним расходовать OpenAI-баланс.

## Telegram Mini App

1. Создай бота в `@BotFather`.
2. Добавь его токен в серверную переменную `TELEGRAM_BOT_TOKEN`.
3. Размести приложение на публичном HTTPS-адресе.
4. В `@BotFather` открой настройки бота и выбери `Configure Mini App`, затем
   укажи HTTPS-адрес приложения.
5. Тем же адресом можно настроить `Menu Button`.

При запуске из Telegram приложение отправляет `initData` серверу. Сервер
проверяет HMAC-подпись и срок данных, после чего создаёт или открывает аккаунт
Telegram. Непроверенные данные из браузера не используются.

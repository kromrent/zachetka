# Зачётка

Персональное PWA для подготовки к вступительному экзамену по программам 09.04.01.

## Возможности

- тесты по 8 вопросов с одним правильным ответом;
- письменные ответы с AI-оценкой по официальной шкале 0–25;
- Java-задачи из экзаменационной программы с редактором и AI-оценкой 0–50;
- полный билет: два вопроса и задача, 60 минут, максимум 100 баллов;
- локальное сохранение прогресса и черновика;
- установка на главный экран телефона как PWA и офлайн-загрузка интерфейса.

В папке `extracted/ocr` находится локально распознанный текст всех трёх исходных PDF.

## Запуск

```bash
npm install
cp .env.example .env
npm run dev
```

Интерфейс откроется на адресе Vite, API работает на `http://localhost:8787`.

Для production:

```bash
npm run build
npm start
```

После сборки единый сервер отдаёт приложение и API на `http://localhost:8787`.

## AI-проверка

В `.env` необходимо указать `OPENAI_API_KEY`. Ключ используется только сервером и не попадает в браузер. По умолчанию применяется `gpt-5.6-luna`; модель можно заменить через `OPENAI_MODEL`.

Без ключа тесты, редактор, таймер и локальный прогресс работают, а AI-проверка показывает понятное сообщение о настройке.

## Java

`ENABLE_LOCAL_JAVA=true` включает локальную проверку компиляции через `javac`. Использовать её следует только на личном компьютере. Она не является безопасной песочницей для публичного сервера. На хостинге выполнение кода нужно вынести в отдельный изолированный контейнер с лимитами CPU, памяти, времени и без сети.

## Телефон

После размещения приложения на HTTPS открой ссылку в браузере телефона и выбери «Добавить на главный экран». Интерфейс и сохранённый прогресс доступны как PWA; AI-проверке требуется интернет.

## Аккаунт и база

Приложение использует PostgreSQL. Подключение задаётся переменной
`DATABASE_URL`; локально можно использовать базу `zachetka` из Postgres.app,
а на хостинге — выданную облачным PostgreSQL строку. Пароли хешируются через `scrypt`, а сессия
хранится в защищённой `HttpOnly` cookie.

После регистрации локальный прогресс загружается в аккаунт. Изученные вопросы,
черновики, результаты, задачи и эталонные ответы затем синхронизируются
автоматически. AI-маршруты доступны только авторизованному пользователю, поэтому
публичная ссылка не позволяет посторонним расходовать OpenAI-баланс.

## Telegram Mini App

1. Создай бота в `@BotFather`.
2. Добавь его токен в серверную переменную `TELEGRAM_BOT_TOKEN`.
3. Размести приложение на публичном HTTPS-адресе.
4. В `@BotFather` открой настройки бота и выбери `Configure Mini App`, затем
   укажи HTTPS-адрес приложения.
5. Тем же адресом можно настроить `Menu Button`.

При запуске из Telegram приложение отправляет `initData` серверу. Сервер
проверяет HMAC-подпись и срок данных, после чего создаёт или открывает аккаунт
Telegram. Непроверенные данные из браузера не используются.
